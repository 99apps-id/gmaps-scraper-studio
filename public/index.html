FAQ — Pertanyaan Umum

GMST Scraper

Berapa lama masa trial gratis?

3 hari sejak aplikasi pertama kali dibuka di perangkat ini. Penghitung tampil di pill lisensi bilah atas.

Bagaimana cara mendapatkan kode aktivasi?

Kirim email ke support@99apps.id dengan mencantumkan ID instalasi (lihat menu Pengaturan → Lisensi). Setelah pembayaran (QRIS), kode dikirim ke email Anda.

Saya ganti perangkat, bagaimana?

Buka menu Pengaturan → Lisensi → Nonaktifkan lisensi perangkat ini di perangkat lama, lalu masukkan kode yang sama di perangkat baru.

Apakah data hasil scrape saya terlihat orang lain?

Tidak. Data tersimpan lokal di perangkat Anda (aplikasi desktop) atau file Excel Anda sendiri (dashboard). Server hanya memproses pencarian.

Apakah harus selalu online?

Ya, untuk menjalankan scraping (diproses via server) dan verifikasi lisensi berkala.

Kode saya ditolak padahal baru diterima?

Periksa pengetikan (huruf besar semua, tanpa spasi). Bila tetap gagal, hubungi support@99apps.id dengan ID instalasi Anda.
